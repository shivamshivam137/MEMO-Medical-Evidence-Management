2. `prescription_metro_hospital.jpg` — Outpatient prescription note from Metro Multispeciality Hospital.
3. `lipid_panel_citymed.pdf` — Lipid Profile panel report from CityMed Laboratories.
4. `ultrasound_abdomen_summary.pdf` — Abdominal ultrasound radiology impression summary from HealthFirst Imaging.

*Note: All medical data, patient names, and doctor identities are entirely fictional.*
